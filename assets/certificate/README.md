To refresh, re-run the kit's build and copy the same three files:

    master/png/easyfix-certificate-frame-3508.png
    master/svg/easyfix-certificate-frame.svg
    certificate-layout.json

The layout JSON must be taken from the SAME kit commit as the artwork — it is
emitted from one geometry pass with the SVG, and a mismatched pair puts text in
the wrong place with nothing to flag it.

The Easyfix_CRM_UI vendors the same files through
`scripts/sync-brand-assets.mjs`, which records the kit commit in
`brand-assets.lock.json`. Keep the two in step: the CRM's preview and this
renderer must agree, and they only do so while both point at one kit commit.
